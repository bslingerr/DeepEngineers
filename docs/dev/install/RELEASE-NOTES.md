# DeepEngineers 1.0.0

Subnautica's ocean planet 4546B in the Space Engineers Star System, rendered by your own copy of Subnautica. Both games are required, both bought on Steam.

## Requirements

Windows 10 or 11, 64-bit. Space Engineers and Subnautica (the first game) installed through Steam.
16 GB of RAM minimum

## Install

1. Download DeepEngineers-1.0.0.zip, unzip it anywhere.
2. Run Install.cmd. Read its last line: INSTALL PASS.
3. Run DeepEngineers from the desktop. New Game, Star System, Start, pick the 4546B capsule.

The full guide: https://github.
