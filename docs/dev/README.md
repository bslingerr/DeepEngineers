# DeepEngineers (codename)

A Space Engineers × Subnautica mashup: Space Engineers runs the whole game (player, survival, building,
ship physics); when you dive into the ocean planet, the picture switches to Subnautica, which renders its
water, biomes, lighting and creatures around your Space Engineers ship.

Status: **architecture phase** (nothing runs yet).md` for the journal and `docs/` for the
recon reports, the architecture and the bridge contract.

Both games must be owned (Steam). This repository ships only its own code and documents: no game files,
no extracted assets, no decompiled code.

Built with AI tool using the universal-modder method.
