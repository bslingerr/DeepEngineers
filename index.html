DeepEngineers

A Space Engineers × Subnautica mashup. Space Engineers runs the game: your character, survival, building and ship physics. When you dive into the ocean planet, the picture becomes Subnautica's: its water, biomes, light and creatures around your Space Engineers ship. Both games must be owned; nothing of either game is shipped.

    Install

    The release folder carries the full README with every option and the troubleshooting section. In short:

    1. Own Space Engineers and Subnautica on Steam; install Python 3.10 or newer from python.org.
    2. In Space Engineers: turn on Experimental mode (Options > Game) and set the window mode to Fullscreen window (Options > Display).
    3. In Steam, for both games: Properties > Updates > Only update this game when I launch it (DeepEngineers is pinned to the exact game builds).
    4. Subscribe to the Space Engineers Workshop items Water Mod (2200451495) and Text HUD API (758597413); start Space Engineers once so they download, then close it.
    5. In Subnautica, make a Freedom save (New Game > Freedom, save in the lifepod, quit).
    6. Unzip the DeepEngineers folder anywhere outside the game folders and run Install.cmd. It checks everything, downloads the two loaders (Pulsar for Space Engineers, BepInEx for Subnautica) with their checksums, installs the plugins, the planet mod and a ready world called DeepEngineers, and records every file it adds so Uninstall.cmd can undo exactly that.
    7. Play with Play.cmd.

    About

    DeepEngineers is a fan project. It ships only its own code and documents: no file of either game, no extracted asset, no decompiled code. Everything Subnautica shows is read from your own install while you play. Built with AI agents (Claude Code).

    Requirements data: data/requirements.json, written by the project's measurement analyzer from the plugins' own per-second rows.
