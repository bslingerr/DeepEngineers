# DeepEngineers release allowlist: every file the release folder may hold (check 1 of
# tools/release/check_release.py). Any other file fails the lint.
#
# Format: <path relative to the release folder> [required] [sha256=<hex>] [build=<path relative to the repository>]
# path exact, or a glob: * within one folder, ** across folders, ? one character (case-insensitive)
# required the file must be present
# build= the file must equal that repository file byte for byte; "dir/** build=src/x/**" maps the rest of the
# path. The plugins must equal the RELEASE-FLAVOUR build (build.ps1 -Flavor release; DEEPENG_RELEASE):
# a dev build in the release folder fails here.
# Layout: tools/release/make_release.py (run it with --se-bin/--sn-bin pointing at bin\ReleaseFlavor\Release\...).
